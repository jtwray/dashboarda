# Slice S2 · Fresh source discovery and high-signal alerts

**Status:** Planned; requires S1.

**In scope:** A defined list of public/approved sources; per-source access/policy notes; canonical IDs; post-time provenance; source availability checks; scheduler heartbeat; low-noise alert threshold; error/degraded-source reporting. Initial source set should be tiny (e.g., accessible n8n / Make community + lawful marketplace notifications/links) rather than 10 fragile scrapers.

**Acceptance:** Duplicate replays don't create leads; a zero-result run is distinguishable from broken search; source reported 'unverified' when original page inaccessible; alert only for user-approved threshold and frequency; error logs and links to originals; privacy-safe. One genuine permitted opportunity may be enough for end-to-end test, otherwise use labeled synthetic fixtures.

**Exclude:** protected scraping, auto-bidding, unsolicited posts, proposal generation, broad full-time job scans.
