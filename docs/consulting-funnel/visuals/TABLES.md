# Markdown chart and table archive

## Five inhibiting factors

| Problem | Impact |
|---|---|
| Reading instead of acting | Too much scrolling/comparison overhead |
| Duplicates and false freshness | Recycled old leads crowd out truly new gigs |
| Inconsistent ranking | No comparable score across rate, fit, budget, age, competition |
| Conversion not tracked | Cannot tell whether discovery leads to replies or work |
| No outcome feedback | Timing, rate and source strategy remain guesses |

## Monitoring windows (experiments, not established best times)

| Window | Eastern time | Hypothesis |
|---|---|---|
| Morning | 6–9 AM | Review overnight US/overseas posts |
| US daytime | 9 AM–4 PM | Capture new US buyer requests during active hours |
| Late evening | 7–11 PM | Capture West Coast end-of-day posts / other timezones |

## Priority score (max 100, heuristic)

| Factor | Points |
|---|---:|
| Verified skill fit | 25 |
| Expected pay for realistic effort | 20 |
| Posting freshness | 15 |
| Buyer credibility | 15 |
| Competition | 10 |
| Feasible bounded scope | 10 |
| Timezone / location advantage | 5 |
| **Total** | **100** |

## Funnel

| # | Stage | Main deliverable |
|---|---|---|
| 01 | Discover | Source URL, deduped opportunity |
| 02 | Qualify | Verified buyer/posting details + score |
| 03 | Prepare | Evidence-backed proposal and estimate |
| 04 | Apply | Owner-authorized application record |
| 05 | Follow up | Reply/interview/negotiation history |
| 06 | Deliver | Signed work, payment, actual effort |

## Success metrics

| Metric | Interpretation |
|---|---|
| Applications | Number of qualified proposals *actually submitted* |
| Response rate | Replies per delivered application within defined tracking window |
| Win rate | Contracts won divided by qualified submitted proposals |
| Net earnings per total hour | Collected revenue less direct fees divided by acquisition + delivery hours |
